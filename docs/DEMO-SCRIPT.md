# 시연 대본

대상: API Discovery, Code Base Integration, Sensitive Data Discovery, BOLA 탐지를 평가하는 보안/플랫폼 담당자.

## 0. 사전 준비

- VM에서 `docker compose up -d api`가 떠 있고 XC origin pool이 healthy인지 확인
- 제너레이터가 LB FQDN을 대상으로 **몇 시간 이상** 돌아왔는지 확인
- GitHub 저장소가 push되어 Code Base Integration 스캔이 끝났는지 확인
- `docs/ENDPOINT-MATRIX.md`와 Shadow 경로 정답지를 미리 열어둘 것

## 1. 상황 설명 (2분)

작은 디지털 뱅킹 API입니다. 로그인, 계좌, 이체, 카드. 겉보기엔 평범한 Express 서비스입니다.

여기서 두 가지를 아직 아무도 모릅니다. 코드 일부는 죽어 있고, 실제 들어오는 트래픽 일부는 애초에 이 코드에서 나온 게 아닙니다.

## 2. 코드 기반 인벤토리 (3분)

XC Console → API Management → Code Base Integration 결과를 엽니다.

엔드포인트 개수가 17개(Common + Code-only)로 잡히는 걸 짚습니다. 그다음 Code-only 쪽을 봅니다. legacy v0 라우트, 안 쓰는 beneficiaries, 콜센터 전용 카드 삭제, 미출시 statements, 피처 플래그로 꺼둔 대출 신청.

> 이것들은 소스에서 정상적으로 등록되고, 실제로 도달 가능하고, 스캔에도 잡힙니다. 그런데 아무도 호출하지 않습니다. 조용히 공격면으로만 남아 있는 코드죠.

## 3. 트래픽 기반 인벤토리 (3분)

XC Console → API Endpoints의 트래픽 기반 화면을 엽니다.

같은 Common 세트가 여기도 있습니다. 그런데 코드 스캔에는 전혀 없던 엔드포인트 6개가 더 보입니다. 관리자 사용자 덤프, 디버그 설정 노출, PII CSV, 운영 정산 트리거, 문서화 안 된 차기 버전 잔액 조회, 파트너 콜백.

(경로는 저장소 문서에 없습니다. 화면에 띄우거나 따로 들고 있는 정답지를 보고 말하세요.)

> 이게 Shadow API입니다. 트래픽은 실제로 여기 들어오고 있는데, 리뷰와 버전 관리를 거친 코드베이스에는 존재하지 않습니다. 이 데모에서는 릴리스 프로세스 밖에서 VM에 얹힌 운영 설정 파일로 붙었습니다. 실제 현장에서 shadow API가 생기는 방식과 정확히 같습니다. 급한 핫패치, 누가 켜놓고 잊은 디버그 엔드포인트, 아무도 문서화 안 한 파트너 연동.

## 4. 버킷 대조 (2분)

classification 화면을 띄우고 Common / Code-only / Traffic-only를 나란히 보여줍니다. 11 / 6 / 6이 매트릭스와 맞는지 확인합니다.

## 5. Sensitive Data Discovery (2분)

`metricsPiiExport` 엔드포인트를 직접 호출하거나 캡처된 트래픽을 보여줍니다. 사용자별 카드번호와 주민번호 형식 값이 담긴 CSV가 그대로 나옵니다. XC가 이 응답을 카드번호/주민번호 패턴으로 표시한 걸 같이 띄웁니다.

> 이 shadow 엔드포인트는 문서화가 안 된 정도가 아니라 실제로 민감 데이터를 흘리고 있습니다. 그리고 XC는 이 엔드포인트의 존재조차 아무도 알려주지 않은 상태에서 그걸 잡아냈습니다.

## 6. BOLA (2분)

`GET /api/v1/accounts/{accountId}` 트래픽 중 한 사용자 토큰이 다른 사용자 계좌 id로 호출된 건을 보여줍니다. 제너레이터가 이런 호출을 소량 섞어 보냅니다.

> 이건 shadow가 아닙니다. 문서화돼 있고, 코드에 있고, 정상적으로 예상되는 엔드포인트입니다. 다만 인가 버그가 있습니다. 호출자가 그 계좌 주인인지 검사하지 않습니다. 알려진 엔드포인트에서도 이런 접근 패턴은 걸립니다.

## 7. 마무리 (1분)

> 앱 하나에서 성격이 다른 세 가지가 나왔습니다. 공격면만 넓히는 죽은 코드, PII를 흘리는 문서화되지 않은 shadow API, 그리고 멀쩡히 문서화된 엔드포인트의 인가 버그. Code Base Integration과 API Discovery를 같이 걸면 이 셋이 한 화면에서 갈립니다.
